# Five Nights at Freddy's: Sister Location

## Overview

Five Nights at Freddy's: Sister Location sends you to Circus Baby's Entertainment and Rental, a sister facility to Freddy Fazbear's Pizza. Each night brings scripted tasks, vent navigation, and story-driven encounters with a new cast of animatronics led by Circus Baby.

This browser version is a **fan-made HTML5 port** from the [hd_fnaf](https://github.com/irv77/hd_fnaf) project. It is **not** an official Scott Cawthon release and is not approved by or associated with the original creator.

## Game Information

**Genre:** Horror / Survival

**Developer:** Fan port (original game by Scott Cawthon)

## Features

- Story-driven night shifts with unique objectives each night
- Vent crawling and room-to-room navigation
- Circus Baby, Ballora, Funtime Freddy, and more
- Voice-acted narrative sequences
- Runs in the browser with no install

## How to Play

Follow nightly instructions from HandUnit and complete maintenance tasks. Navigate vents, manage power, and survive encounters with animatronics that behave differently each night. Pay attention to the story — choices and timing matter.

## Controls

- Mouse to interact with UI, vents, and task controls
- Press `-=` for fullscreen (per hd_fnaf)

## Platform Support

Runs in desktop browsers when served locally via the game manager or a static HTTP server. Self-contained with relative asset paths.

## Why Play

Sister Location reinvented FNAF with cinematic storytelling and varied gameplay each night — one of the most narrative-driven entries in the series.
