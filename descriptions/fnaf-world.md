# FNAF World

## Overview

FNAF World is a party-based RPG spin-off starring chibi versions of the FNAF animatronics. Explore an overworld, battle enemies in turn-based combat, recruit characters, and uncover secrets across multiple endings.

This browser version is a **fan-made HTML5 port** from the [hd_fnaf](https://github.com/irv77/hd_fnaf) project. It is **not** an official Scott Cawthon release and is not approved by or associated with the original creator.

## Game Information

**Genre:** Horror / RPG / Adventure

**Developer:** Fan port (original game by Scott Cawthon)

## Features

- Turn-based party combat with dozens of characters
- Overworld exploration and hidden areas
- Character recruitment and team building
- Multiple endings and secret content
- Runs in the browser with no install

## How to Play

Build a party of animatronic characters and explore the map. Engage in random and boss battles using each character's abilities. Level up your team, find hidden chips and characters, and progress through the story to unlock different endings.

## Controls

- Mouse and keyboard for movement, menus, and combat
- Press `-=` for fullscreen (per hd_fnaf)

## Platform Support

Runs in desktop browsers when served locally via the game manager or a static HTTP server. Self-contained with relative asset paths.

## Why Play

A lighter, exploration-focused break from the mainline jump-scare formula — packed with fan-service, secrets, and surprisingly deep RPG mechanics.
